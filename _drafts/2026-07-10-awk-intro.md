如果只用过一个命令来处理文本——大概是 `grep`。如果需要多做一些操作，可能会用到 `sed`。它们各有各的擅长领域：grep 擅长查找，sed 擅长替换。但面对稍微复杂一点的任务——比如「打印第二列数据」或者「统计文件行数」——这两个工具就开始显得捉襟见肘了。

这时候该轮到 awk 上场了。

---

## awk 的名字

awk 这个名字取自三位作者姓氏的首字母：**A**lfred **A**ho、**P**eter **W**einberger 和 **B**rian **K**ernighan。说到后者，写过 C 语言的人应该不陌生——他就是 K&R 里的那个 K。

它诞生于 1977 年的贝尔实验室，最初是 Version 7 Unix 的一部分。四十多年过去了，它还是每个 Unix 系统里标配的工具之一。和它同时代的很多软件早已进了博物馆，awk 却至今仍在无数人的终端日常里活跃着。

名字的读音和一种海鸟 auk 一样，读作 /ɔːk/。有时候也被直接读作三个字母「A-W-K」。

## 核心逻辑：pattern { action }

awk 的能力其实不小——它有变量、数组、控制流、函数，本质上是一套完整的脚本语言。但 awk 真正独特的地方不在于它有多强大，而在于它做了别的语言懒得做的事：**自动帮我们读文件、拆字段、逐行处理**。

它的基本结构是这个样子的：

```awk
pattern { action }
```

对 awk 来说，输入文件被看作一叠「记录」（record），默认每行是一条记录。每条记录又被分割成若干「字段」（field）。awk 读入一条记录，检查它是否匹配某个 pattern，如果匹配，就执行对应的 action。然后自动跳到下一条记录，重复这个过程。

如果把 pattern 省略，action 会在每行都执行一次。如果把 action 省略（不写花括号），默认动作就是 `{ print }`——相当于 `cat`。

看看最直观的例子：

```text
# 一个简单的 CSV 文件 scores.txt
Name,Score
Alice,85
Bob,92
Charlie,78
```

```zsh
# 只打印第二列
awk -F, '{ print $2 }' scores.txt
```

`-F,` 告诉 awk 用逗号做字段分隔符。`$2` 表示第二个字段。`$0` 表示整条记录，`$1` 是第一个字段，依此类推。

## 内置变量

awk 自带一批很有用的内置变量，不需要声明，随时可用。

| 变量  | 含义                     | 默认值 |
|-------|--------------------------|--------|
| `$0`  | 整条记录                 |        |
| `$1`, `$2`, ... | 各字段           |        |
| `NF`  | 当前记录的字段数量       |        |
| `NR`  | 已处理的记录总数（行号） |        |
| `FS`  | 输入字段分隔符           | 空格   |
| `OFS` | 输出字段分隔符           | 空格   |
| `RS`  | 输入记录分隔符           | 换行符 |
| `ORS` | 输出记录分隔符           | 换行符 |

用几个命令很容易理解它们的作用：

```zsh
# 打印每行行号和内容
awk '{ print NR, $0 }' scores.txt

# 打印每行的字段数量
awk '{ print NF }' /etc/paths

# 打印第一列，列之间用 tab 隔开
awk -F: 'BEGIN { OFS="\t" } { print $1, $3 }' /etc/passwd
```

`NF` 特别有用——要取一行里的最后一个字段，不管它有多少列，`$NF` 就行了。

## 用条件筛选行

pattern 最常见的用法之一是条件判断：

```zsh
# 只打印长度超过一行的内容
awk 'length($0) > 80' somefile.txt

# 打印第 3 到第 6 行
awk 'NR >= 3 && NR <= 6' somefile.txt

# 只打印名字叫 Alice 的那一行
awk -F, '/Alice/' scores.txt
```

pattern 也可以是正则表达式，用斜杠包起来。`/Alice/` 表示任何包含 Alice 的行。

```zsh
# 用 $1 做条件：只处理第一个字段以 A 开头的行
awk -F, '$1 ~ /^A/' scores.txt
```

这里的 `~` 是匹配运算符，表示「匹配这个正则」。对应的 `!~` 表示「不匹配」。

---

## BEGIN 和 END

有些操作需要在处理文件之前或之后做。比如打印表头、算总计。BEGIN 和 END 就干这个。

```awk
BEGIN { print "=== Report ===" }
      { print $0 }
END   { print "=== Done ===" }
```

`BEGIN` 里的代码在处理任何输入之前执行。`END` 在读完所有记录之后执行。这个特性让 awk 很适合做简单的报表。

---

## 简单计算

awk 支持数值运算。把这个和自动逐行处理结合起来，就能轻松做统计。

```zsh
# 统计行数（效果类似 wc -l）
awk 'END { print NR }' scores.txt
```

这大概是 awk 最经典的 one-liner 之一。`NR` 在每行结束时自动递增，到 `END` 块的时候就是总行数了。

```zsh
# 求和：统计第二列的总分
awk -F, 'NR > 1 { sum += $2 } END { print sum }' scores.txt
```

跳过第一行（表头），从第二行开始累加第二列的值。

```zsh
# 平均数
awk -F, 'NR > 1 { sum += $2; count++ } END { print sum / count }' scores.txt
```

当然这些用 Python 也能写：

```python
import csv
with open('scores.txt') as f:
    reader = csv.reader(f)
    next(reader)  # skip header
    scores = [int(row[1]) for row in reader]
    print(sum(scores))
    print(sum(scores) / len(scores))
```

Python 的写法更可读、更灵活，但 awk 一行命令就搞定，不用写脚本、不用处理文件打开和关闭。随手查一下数据这种场景，敲一行 awk 确实比写个 Python 脚本快太多。

## 从外部传入变量

awk 脚本里用的变量值，可以用 `-v` 从 shell 传进去。

```zsh
# 查找分数超过某个阈值的行
threshold=80
awk -F, -v t="$threshold" 'NR > 1 && $2 > t' scores.txt
```

不加 `-v` 的话，在 awk 脚本里直接引用 shell 变量会出错，因为它的脚本语法里 `$` 另有含义（字段引用）。`-v` 是标准做法，写法也干净。

## 实战：解析 /etc/passwd

`/etc/passwd` 是 awk 教科书式的好例子。文件格式简单：

```text
root:x:0:0:root:/root:/bin/bash
daemon:x:1:1:daemon:/usr/sbin:/usr/sbin/nologin
...
```

每一行由 7 个冒号分隔的字段组成。用 awk 可以随手做各种查询：

```zsh
# 列出所有用户名和他们的登录 shell
awk -F: '{ print $1, $7 }' /etc/passwd

# 只列出 UID 大于 1000 的用户（非系统用户）
awk -F: '$3 > 1000 { print $1 }' /etc/passwd

# 看看系统里用 bash 的用户
awk -F: '$7 ~ /bash/' /etc/passwd
```

虽然不是每个系统都有 `/etc/passwd`（macOS 最近几个版本改用了 opendirectoryd），但这个文件作为教学素材的地位从未动摇。

## 和 Python 的简单对比

前面已经看到，awk 适合做「看一眼就扔」的文本处理。写一行命令就有输出，没有额外的仪式感。

Python 的优势在于可维护性、复杂逻辑、数据类型处理。awk 的优势在于速度和便利性——它天生就是为文本行设计的。

两者不是竞争关系。很多人的日常是：用 awk 快速浏览和粗筛数据，发现有价值的线索后再用 Python 做深度分析。工具链里多一个选择，总比少一个好。

## 接下来可以试试

试试这几个，感受一下 awk 的节奏：

```zsh
# 自己的历史命令里最常用的 10 个
history | awk '{ print $2 }' | sort | uniq -c | sort -rn | head -10

# 统计一个日志里每个 IP 的出现次数
awk '{ print $1 }' access.log | sort | uniq -c | sort -rn

# 当前目录下最大文件的文件名
ls -l | awk 'NR > 1 { print $5, $9 }' | sort -rn | head
```

awk 还有不少可以深入的东西——关联数组、多维模拟、自定义函数——那是后面的话题。先把这一套 basic moves 练熟，日常的文本处理就能顺手很多。
