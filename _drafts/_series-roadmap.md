## 确认要补的窟窿

以下按推荐写作顺序排列：

### 1. 包管理——通用概念

**为什么补：** 用户反馈中频率最高的缺口。软件安装是命令行最刚需的操作之一。
覆盖内容：
- 包管理器的本质（依赖解析、源、更新策略）
- 各生态的包管理器速览：`apt`（Debian/Ubuntu）、`yum`/`dnf`（RHEL/Fedora）、`brew`（macOS）、`pip`（Python）、`npm`（Node.js）
- 不追求面面俱到，重点讲清楚共用概念

### 2. Homebrew 与现代工具链（🧩 等基础篇收尾后再写）

**为什么补：** 基础篇即将收尾，自然过渡到"安装工具"。且 Homebrew 是 macOS 用户的实际主力包管理器。
覆盖内容：
- Homebrew 安装与常用命令
- 然后引入 ripgrep、eza、bat、fd、htop 等现代替代
- 对比经典 vs 现代工具的设计差异

### 3. 磁盘管理

覆盖内容：
- `df` 查看磁盘空间
- `du` 查看目录大小
- `fdisk`/`gpart` 分区工具
- `mount`/`umount` 挂载

### 4. 用户管理

覆盖内容：
- `useradd`/`usermod`/`userdel`
- `passwd` 密码管理
- `group` 组管理
- 多用户系统的权限模型

### 5. 系统服务管理

**与已有草稿"前后台任务"区分：** 那篇讲的是 Shell 层面的前台/后台进程（`&`、`fg`、`bg`、`jobs`、`nohup`、`disown`），这篇讲系统层面的服务管理。
覆盖内容：
- `systemctl`/`service` 管理后台服务
- systemd 的基本概念

### 6. Tmux / Screen——终端复用

覆盖内容：
- 为什么需要终端复用（远程会话保持、分屏）
- Tmux 基本操作：创建/分离/重连会话
- 窗格与窗口管理

### 7. Make / Makefile

覆盖内容：
- 构建自动化的基本概念（目标、依赖、规则）
- 一个简单的 C 编译例子
- 不深入，够用就行

### 8. Git 入门（🧩 系列内 + 后续独立系列）

**双层计划：** 先在 Command Line 系列里放一篇 Git 入门，覆盖最常用的几个操作，让读者能用起来。后续再独立开一个 Git 系列深入讲。

**本篇（系列内）覆盖：**
- 为什么需要版本控制
- `init` `add` `commit` `log` `status` `diff`
- `push`/`pull` 远程仓库
- 够用即可，不提分支合并

**后续独立系列：**
- 分支与合并、冲突解决
- rebase、stash、reset、revert
- 团队协作工作流

### 💡 关于 "Shell 脚本" 草稿

已有草稿 "Shell 脚本" 建议扩展覆盖以下子主题（一次性讲完，不分拆单篇）：
- Here Document (`<<EOF`) / Here String (`<<<`)
- 命令替换：`$()` 与反引号的区别与陷阱
- Bash 数组：索引数组和关联数组
- Shell 脚本调试：`set -x`、`set -e`、`trap`、错误处理
