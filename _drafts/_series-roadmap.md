## 确认要补的窟窿

以下按推荐写作顺序排列：

### 1. 文件描述符深入（🧩 你刚刚确认的盲点）

**为什么补：** 管道/重定向那篇写了怎么用，但文件描述符的底层机制没讲透。
覆盖内容：
- `0 1 2` 的底层含义
- `2>&1`、`1>&2` 到底在干什么
- 自定义描述符：`exec 3>file`
- `/dev/fd`、`/dev/null`、`/dev/zero`

### 2. 正则表达式专篇（🎯 标准：Perl/Python 风格）

**为什么补：** 覆盖 Python/JS/现代 CLI 工具都用的一套标准，独立于 grep 文章。
覆盖内容：
- 基本元字符：`.` `^` `$` `*` `+` `?` `[]` `()`
- 分组与捕获
- 贪婪 vs 懒惰
- 字符集速记符：`\d` `\w` `\s`
- 前瞻断言（可选）
- 用 `grep -P`、`sed -E` 和 Python 各演示一遍

### 3. awk（📝 有计划，未起草）

**为什么补：** 经典 Unix 文本处理三剑客（grep/sed/awk）的最后一块。
覆盖内容：
- awk 的基本结构：`pattern { action }`
- 内置变量：`$0` `$1` `NF` `NR` `FS` `OFS`
- 条件过滤
- 统计/求和/计算
- 从 csv 数据提取信息

### 4. Homebrew 与现代工具链（🧩 等基础篇收尾后再写）

**为什么补：** 基础篇即将收尾，自然过渡到"安装工具"。
覆盖内容：
- 包管理器是什么、为什么需要
- Homebrew 安装与常用命令
- 然后引入 ripgrep、eza、bat、fd、htop 等现代替代
- 对比经典 vs 现代工具的设计差异

### 5. Unix 哲学（🎯 可做系列收尾）

**为什么补：** 一本书（TAOUP）的开头，却是系列最好的结尾。
覆盖内容：
- DO-ONE-THING-WELL
- 管道组合
- 文本是通用接口
- 从系列中举具体例子：dash 命令的演变、grep/sed/awk 的配合
- 对比"一刀切"的大工具（GUI IDE 等）

### 6. Git 基础（📂 单开类目）

**独立计划：** Git 系列，不混入 Command Line。
首批覆盖：`init` `add` `commit` `push` `pull` `log` `status` `diff`。按需扩展分支、合并、冲突解决。
