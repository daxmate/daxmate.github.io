到现在我们已经敲了上百条命令了。有没有这样的时候——刚才敲了一条很长的命令，结果发现少打了个字母，想改一下但不想重敲一遍。

这篇就是讲这个的。Shell 会记住我们敲过的每一条命令，我们只需要知道怎么翻出来。

---

## 上箭头：最简单的回放

在终端里按 **上箭头**（↑），上一条命令就出来了。再按，上上条，一直往上翻。**下箭头**（↓）往回翻。

这是最直观的方式。但它的局限也很明显——只能按时间倒序一层层翻。如果要找的是 50 条之前的命令，↑ 得按 50 下。

---

## 查看完整历史：`history`

想看最近敲过哪些命令，直接敲：

```zsh
history
```

会列出一大串：

```
  501  cd ~/cmd_practice
  502  ls -la
  503  cat hello.txt
  504  find . -name "*.txt"
  505  history
```

每一条前面都有编号。只看最近 10 条：

```zsh
history 10
```

### 用编号重跑命令

看到某条命令的编号，用 `!编号` 直接重跑：

```zsh
!503
```

Shell 会把 `!503` 展开成 `cat hello.txt` 然后执行。

### 重跑上一条

```zsh
!!
```

`!!` 等价于"上一条命令"。最常见的场景是——敲了一条需要 `sudo` 的命令但忘了加：

```zsh
rm /etc/hosts
# → Permission denied

sudo !!
# → sudo rm /etc/hosts
```

### 重跑最后一个参数：`!$`

很多时候，上一条命令的最后一个参数正好是下一条命令需要的：

```zsh
mkdir -p ~/projects/myapp
cd !$
```

`!$` 展开成上一条命令的最后一个参数——`~/projects/myapp`。直接 `cd` 进去。

这个组合太常用了：先建目录，再进目录，一气呵成。

---

## 搜索历史：`Ctrl+R`

上箭头一层层翻太慢，`!编号` 需要记得编号。真正高效的方式是**反向搜索**：`Ctrl+R`。

按下 `Ctrl+R`，终端变成：

```
bck-i-search: _
```

开始打字，Shell 会从最近的命令开始往前搜，实时匹配输入的内容。比如我们要找一条 `tar` 命令：

按下 `Ctrl+R`，输入 `tar`：

```
bck-i-search: tar
```

如果显示的不是我们要的那条，再按一次 `Ctrl+R`，跳到更早的一条。

找到了直接按 **回车** 执行，或者按 **左右箭头** 退出搜索模式但保留命令供我们编辑。

`Ctrl+R` 是命令行效率的分水岭——不会用之前 ↓ 按到天荒地老，学会之后一秒定位任何敲过的命令。

---

## 只选不跑：查看上次命令

有时候想确认 `!编号` 到底会展开成什么，但不想直接执行。`!!:p` 和 `!编号:p` 只显示不执行：

```zsh
!!:p
# → 显示上一条命令的内容，但不跑

!503:p
# → 显示编号 503 的命令内容，但不跑
```

确认没问题之后，再单独敲 `!!` 或直接按回车。

---

## 历史记录的配置

Shell 把历史命令保存在一个文件里（zsh 默认是 `~/.zsh_history`）：

```zsh
tail ~/.zsh_history
```

几个有用的配置项（放在 `~/.zshrc` 里）：

```zsh
HISTSIZE=10000              # 内存中记录多少条
SAVEHIST=10000              # 文件中保存多少条
setopt HIST_IGNORE_DUPS     # 不记录连续重复的命令
setopt HIST_IGNORE_SPACE    # 以空格开头的命令不记录（适合临时打密码）
setopt SHARE_HISTORY        # 多个终端窗口共享历史
```

最后一条 `SHARE_HISTORY` 特别实用——开了多个终端窗口的时候，历史命令是互通的，不用切来切去翻。

## 动手试试

```zsh
# 敲几条命令攒点历史
ls -la
echo "hello"
pwd
cd ~/cmd_practice
find . -name "*.txt"

# 上箭头慢慢翻

# 看历史
history
history 5

# !! 重跑上一条
!!

# Ctrl+R 搜历史
# 按下 Ctrl+R，输入 find，再按 Ctrl+R 继续往前翻

# !$ 取最后一个参数
mkdir -p ~/cmd_practice/history-test
cd !$
pwd

# 只查看不执行
!!:p
```

---

## 小结

| 操作 | 作用 |
|------|------|
| ↑ / ↓ | 逐条翻历史 |
| `history` | 列出所有历史命令 |
| `!编号` | 重跑指定编号的命令 |
| `!!` | 重跑上一条 |
| `!$` | 上一条命令的最后一个参数 |
| `Ctrl+R` | 搜索历史命令，实时匹配 |
| `!!:p` | 只显示上一条的内容，不执行 |
| `!编号:p` | 只显示指定编号命令的内容，不执行 |

`Ctrl+R` 是这篇最重要的一个技巧。习惯了之后，我们会发现自己基本上不再用上箭头了。
