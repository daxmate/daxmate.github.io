前两篇我们把命令行的大门推开了一条缝：先知道了命令行是什么、为什么值得学，又把终端和 Shell 拆开讲清楚了。

现在是时候走进来了。今天的事很简单——学走路。

不是怎么走路的「走」，是**文件的走**。在命令行里，最常做的事就是在文件系统里走来走去：看看这个目录有什么、进那个目录看看、
找某个文件在哪儿。所以第一篇实操文章，就从文件系统漫游开始。

---

## 文件系统：一棵倒着长的树

先理清楚一个概念。

电脑里的所有文件，不是杂乱无章堆在一起的。它们按一个树状结构组织起来，最顶上叫**根目录**，用 `/` 表示。

```zsh
/
├── Applications
├── System
├── Users
│   └── dax
│       ├── Desktop
│       ├── Documents
│       └── Downloads
└── usr
    ├── bin
    └── local
```

根目录下面有几个大的子目录，每个子目录下面又可以有很多子目录，层层嵌套。就像往地上扔了一棵树，根朝上、枝丫向下的那种感觉。

Mac 也好，Linux 也好，只要是 Unix 系的操作系统，文件系统都是这个底子。Window 是 `C:\\、D:\\` 那一套，逻辑上也是类似的树，
不过那是另外一回事了，我们先不管它。

---

## 我在哪：`pwd`

打开终端，看到了提示符和一个光标。这时候第一个问题就是：

**我现在在哪儿？**

敲一下这个命令，Shell 就会告诉你答案：

```zsh
pwd
```

```
/Users/dax
```

`pwd` 是 **Print Working Directory** 的缩写——打印当前工作目录。说人话就是：我现在站在这棵树的哪个位置。

`/Users/dax` 就是你的 home 目录，也是每次打开终端之后默认待的地方。

> `~` 就是 `/Users/你的用户名/` 的简写。上一篇我们讲过，提示符里的 `~` 就是这个意思。

---

## 这里有什么：`ls`

上篇我们试过 `ls -la`。`ls` 就是 **List** 的缩写，它的本分就是把这个目录里的东西列出来。

不加选项的时候：

```zsh
ls
```

```
Applications	Desktop		Documents	Downloads	Movies	Music	Pictures
```

很简洁，只有名字。如果加上 `-l`（长格式）：

```zsh
ls -l
```

```
drwx------@  6 dax  staff    192  6月 27 10:00 Applications
drwx------+  4 dax  staff    128  6月 26 14:30 Desktop
drwx------+  4 dax  staff    128  6月 27 09:15 Documents
drwx------+ 16 dax  staff    512  6月 27 11:20 Downloads
```

每个文件都能看到权限、所有者、大小、修改时间。

看第一列那串字符，比如 `drwx------@`，它告诉我们这个文件是谁的、谁能对它做什么。简单拆一下：

- **第 1 个字符**：文件类型。`d` 是目录（Directory），`-` 是普通文件，`l` 是链接
- **第 2-4 个字符**：文件**所有者**（Owner）的权限——r 可读、w 可写、x 可执行
- **第 5-7 个字符**：文件所属**用户组**（Group）的权限
- **第 8-10 个字符**：**其他人**（Others）的权限

所以 `drwx------` 的意思是「这是一个目录，所有者可以读写和执行，其他人什么都不能做」。

> 文件权限是个挺大的话题，这里先有个基本概念就行。后面会专门用一篇来好好聊聊它。

再加上 `-a` 就能连隐藏文件一起显示：

```zsh
ls -la
```

会多出一批以 `.` 开头的文件，比如 `.zshrc`、`.gitconfig`。在 Unix/Linux 的世界里，名字以 `.` 开头的就是隐藏文件，`ls` 默
认不显示它们。

日常我几乎只用 `ls -la` 和 `ls` 两个变体。没必要把所有选项都背下来，记几个常用的就够了。

## 去别处：`cd`

`cd` 是 **Change Directory** 的缩写，用来在目录之间切换。

用法极其简单：

```zsh
cd 目录名
```

试试：

```zsh
cd Downloads
pwd
```

```
/Users/dax/Downloads
```

看，进去了。再退回来：

```zsh
cd ..
pwd
```

```
/Users/dax
```

`..` 代表**上一级目录**。这是文件系统漫游里最常用的两个特殊目录之一。另一个是 `.`，代表**当前目录**。

进门有 `cd 目录名`，出门有 `cd ..`。

从哪来回哪去，用 `cd` 不加参数或者 `cd ~`：

```zsh
cd
pwd
```

```
/Users/dax
```

一键回 home，记住这个就够了。

## 绝对路径 vs 相对路径

关于路径，有一个重要概念。

假设你在 `/Users/dax/Documents`，想去 `/Users/dax/Downloads`，有两种写法：

**相对路径**——从我当前的位置出发：

```zsh
cd ../Downloads
```

从 `Documents` 退上级到 `dax`，再进 `Downloads`。

**绝对路径**——从根目录 `/` 出发，不管我在哪：

```zsh
cd /Users/dax/Downloads
```

区别很好记：**绝对路径以 `/` 开头**，**相对路径不以 `/` 开头**。

用哪个？大部分时候用相对路径——少打字。但如果要从一个很深的地方跳到另一个很深的地方，绝对路径反而更清楚。

多练几次，直觉自然会告诉你什么时候用哪种。

## 三个最实用的技巧

### 1. Tab 补全

这是命令行里**最重要的快捷键**，没有之一。

敲目录名或文件名的时候，不需要敲完——敲几个字母然后按 Tab，Shell 会自动帮你补全剩下的。

```zsh
cd Docu[Tab]
```

自动变成：

```zsh
cd Documents/
```

如果有多个匹配，按两下 Tab 会列出所有可能。省时间、不出错。养成习惯：**宁可多按 Tab，不敲完整词**。

### 2. 回到上一个目录

```zsh
cd -
```

这个很有用。在回退到了一个目录之后，又想回去刚才那个目录——直接 `cd -` 就跳回去了。相当于「刚才那一步走错了，退回去」。

### 3. 关于 pushd 和 popd

如果去查资料，可能会看到 `pushd` 和 `popd` 这两个命令——把当前目录「压入」一个栈，切换到目标目录，完事再「弹出」回来。想
看当前栈里有啥，用 `dirs` 就能列出来。

但这个用法在交互式命令行里其实很少用到，`cd -` 已经够日常用了。`pushd`/`popd` 真正发光的地方是写脚本的时候——临时换个目录
干活，完了 `popd` 就能准确回到原来的位置，不用自己记路径。初学者先知道有 `dirs` 能看栈、有这两个命令就行，以后写脚本遇到
了自然会用上。

## 动手试试

打开终端，跟着来一遍：

```zsh
# 当前在哪儿？
pwd

# home 目录下有什么
ls

# 进 Downloads
cd Downloads

# 看看里面有什么
ls -la

# 回 home
cd

# 用绝对路径进 Documents
cd /Users/你的用户名/Documents

# 回上级
cd ..

# 再回刚才的目录
cd -

# 别忘了 Tab 补全！试试只打几个字母按 Tab
cd Doc[Tab]
```

试试在目录之间来回走几次，感受一下 `pwd`、`cd`、`ls` 这三个命令的配合。它们就像文件系统漫游里的「三件套」——确认我在哪、
看看有什么、走去别处。

## 小结

这一篇我们学会了在命令行里「走路」：

| 命令 | 作用 | 常用搭档 |
|------|------|----------|
| `pwd` | 看当前在哪个目录 | — |
| `ls` | 列出目录内容 | `-l`（详细信息）、`-a`（包含隐藏） |
| `cd` | 切换目录 | `..`（上一级）、`~` 或不加参数（回 home）、`-`（回上一个） |

还搞清楚了绝对路径和相对路径的区别，以及 Tab 补全这个救命技巧。

这些是每天都在用的基本功。下一篇我们开始碰文件本身——怎么在命令行里创建、复制、移动和删除文件。
